 TalentScope – Job Market & Recruitment Intelligence Using SQL

 Project Overview
TalentScope is a SQL-based data analysis project designed to explore job market trends, recruitment activities, salary information, and in-demand skills.

The project uses MySQL to analyze job postings and recruitment data and generate useful insights for job seekers and recruiters.

 Technologies Used
- MySQL
- MySQL Workbench
- SQL

 Database Tables
1. company_table – Company information.
2. job_postings – Job details, salaries, locations, and experience requirements.
3. skills – Technical and professional skills.
4. job_skills – Mapping skills to job postings.
5. applications – Candidate application details and status.
6. interview_process – Interview rounds and progress.

 SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (RANK)
- Data Cleaning and Validation

 Business Analysis
- Identified companies with the most job openings.
- Analyzed the most frequently required skills.
- Compared salaries across job roles.
- Identified locations with more job opportunities.
- Analyzed fresher-friendly job openings.
- Identified remote job opportunities.
- Analyzed application and selection rates.
- Compared interview rounds across companies.

Key Findings
- SQL was the most frequently listed skill in the sample dataset.
- Hyderabad and Bangalore had the highest number of job postings.
- The sample application selection rate was 40%.
- Wipro had a remote job posting in the sample data.

Project Objective
To develop practical SQL skills by working with relational databases and answering real-world business questions through data analysis.
